# OmniGraffle-OxHorse

OmniGraffle 插件：按换行切分文本框，并把 Markdown / Mermaid 画到当前画布。

## 安装最新发布版

在终端执行：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/luomgf/OmniGraffle-OxHorse/main/install.sh)"
```

安装完成后，打开 OmniGraffle，选择 **自动化 → 重新加载插件**。

指定版本：

```bash
OXH_VERSION=v0.1.2 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/luomgf/OmniGraffle-OxHorse/main/install.sh)"
```

安装后立刻打开浮动面板：

```bash
OXH_LAUNCH=1 /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/luomgf/OmniGraffle-OxHorse/main/install.sh)"
```
